## Important implementation details

- **Disconnect root cause:** under R 4.6 + Bioconductor, S4 dispatch evaluates a generic's arguments in an
  isolated context and re-raises errors as plain `simpleError` ("error in evaluating the argument 'x' in
  selecting a method for function 'colnames': …"). A reactive failing `validate()` inside such an argument
  loses its `shiny.silent.error` class; in an observer this closes the session. Calling handlers outside
  cannot see the original error. Fix in `src/global.R`: wrappers in the global environment that force all
  arguments (`list(...)`) and then call the real generic with the same promises — for Bioconductor generics
  that shadow base functions (list `pcago.generics.forced`) at load time, and for the app's own generics at
  session start (`pcago.wrap.app.generics()`; these are `nonstandardGenericFunction`, so the check is
  `is(x, "genericFunction")`). Package code is unaffected.
- **Lockfile generation:** throwaway rocker container; direct deps from `renv::dependencies("src")`
  (+ `txdbmaker`, − knitr/rmarkdown), `BiocManager::install()`, `renv::snapshot(packages = deps)`; CRAN repo
  then set to dated P3M snapshot `https://p3m.dev/cran/2026-11-22` (today's snapshot → 404).
- Extra system libs: liblzma-dev, libbz2-dev (Rhtslib), libtcl8.6/libtk8.6 (tcltk via misc3d → plot3D).
- **Apple Silicon emulation:** GNU tar in Ubuntu 26.04 fails ("Cannot mkdir: Function not implemented");
  renv ignores `TAR` and uses `Sys.which("tar")` → `options(renv.tar.exe = "")` forces R's internal untar.
  renv also can't bootstrap BiocManager itself → install `renv` + `BiocManager` first.
- Shiny Server doesn't forward env vars → `PCAGO_VERSION` goes into `$R_HOME/etc/Renviron.site`.
- rocker's s6 `/init` expects root → `CMD ["shiny-server"]` as user shiny, `SHINY_LOG_STDERR=1`.
- uid 999 via `usermod -u` only (gid 999 is `systemd-journal` on 26.04).
- `docker/browsertest.mjs` must use the "Load example data" link: the importer's manual "Example data"
  source doesn't offer the sample annotation parameters, and collapsed panels don't render their inputs.
