## Important implementation details

- **Lockfile generation:** throwaway rocker container; direct deps via `renv::dependencies("src")`
  (+ `txdbmaker`, − knitr/rmarkdown which only came from README.Rmd); `BiocManager::install()`;
  `renv::snapshot(packages = deps, lockfile = ...)`; CRAN URL then set to dated P3M snapshot
  `https://p3m.dev/cran/2026-11-22` (the 2026-11-23 snapshot was not yet published → 404).
- System libs needed beyond rocker base: build deps from `renv::sysreqs()` incl. **liblzma-dev, libbz2-dev**
  (Rhtslib) and **libtcl8.6 / libtk8.6** (tcltk, loaded by misc3d → plot3D).
- **GNU tar under emulation:** on Apple Silicon (Rosetta amd64), `/usr/bin/tar` in Ubuntu 26.04 fails with
  "Cannot mkdir: Function not implemented". `TAR=internal` alone is not enough because renv picks
  `Sys.which("tar")`; `options(renv.tar.exe = "")` forces R's internal untar.
- renv cannot bootstrap BiocManager itself in this setup → install `renv` + `BiocManager` first.
- Shiny Server does not forward container env vars → `PCAGO_VERSION` written to `$R_HOME/etc/Renviron.site`.
- Started via `CMD ["shiny-server"]` as user shiny (rocker's s6 `/init` expects root). `SHINY_LOG_STDERR=1`.
- Old repo comparison: pcago-unified/src already contains the newer GDPR privacy policy and code fixes;
  nothing needed to be ported from rnajena/pcago.
